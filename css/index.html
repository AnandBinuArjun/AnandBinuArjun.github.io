Beginner CSS Concepts

What is CSS?

CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation of a document written in HTML. It controls the layout, colors, fonts, and overall visual appearance of web pages.

How CSS Works in the Browser

↓

↓

CSSOM Tree
↓
Render Tree
(DOM + CSSOM)
↓

↓

↓
Display on Screen

Why Learn CSS?

Visual Appeal

Create beautiful, engaging websites that attract and retain users

User Experience

Enhance usability with intuitive layouts and responsive designs

Career Opportunities

Essential skill for web developers, UI/UX designers, and digital marketers

Linking CSS to HTML

There are three ways to apply CSS to HTML:

External Stylesheet (Recommended)
<!-- In HTML head section -->
<link rel="stylesheet" href="styles.css">
Internal Stylesheet
<!-- In HTML head section -->
<style>
  body {
    background-color: #f0f0f0;
  }
</style>
Inline Styles
<!-- Directly in HTML elements (Not recommended) -->
<p style="color: blue;">This is a paragraph.</p>

Basic CSS Syntax

CSS rules consist of selectors and declarations:

selector {
  property: value;
  another-property: another-value;
}

Common CSS Properties

Color & Background

color, background-color, background-image

Text Styling

font-family, font-size, text-align

Box Model

margin, padding, border, width, height

Did You Know?

CSS stands for Cascading Style Sheets. The "cascading" part refers to how styles are applied in a hierarchy - from external stylesheets to internal styles to inline styles.

Example: Styling a Paragraph
p {
  color: #333;
  font-family: Arial, sans-serif;
  font-size: 16px;
  line-height: 1.5;
  margin-bottom: 15px;
}

Selectors

Selectors are used to target HTML elements for styling:

Element Selector
p { color: blue; } /* Targets all <p> elements */
Class Selector
.highlight { background-color: yellow; } /* Targets elements with class="highlight" */
ID Selector
#main-header { font-size: 2em; } /* Targets element with id="main-header" */

CSS Specificity

Specificity determines which CSS rule is applied when multiple rules target the same element:

Inline Styles
1000
<p style="color: red;">
ID Selectors
100
#header { }
Classes, Attributes, Pseudo-classes
10
.menu, [type="text"], :hover
Elements, Pseudo-elements
1
p, div, ::before
Example: Specificity in Action
p { color: blue; } /* Specificity: 1 */
.text { color: red; } /* Specificity: 10 */
#paragraph { color: green; } /* Specificity: 100 */
<p style="color: purple;">Text</p> /* Specificity: 1000 */

Intermediate CSS Concepts

The Box Model

Every HTML element is a rectangular box with four areas: content, padding, border, and margin.

CSS Box Model

Content
Margin
Box Model Properties
.box {
  width: 200px;
  height: 100px;
  padding: 20px;
  border: 5px solid #333;
  margin: 10px;
}

Positioning

CSS positioning allows you to control the exact placement of elements on the page.

Static (Default)

Elements follow the normal document flow

Relative

Positioned relative to its normal position

Absolute

Positioned relative to its nearest positioned ancestor

Fixed

Positioned relative to the viewport

Sticky

Toggles between relative and fixed based on scroll position

Positioning Examples
.relative { position: relative; top: 10px; left: 20px; }
.absolute { position: absolute; top: 0; right: 0; }
.fixed { position: fixed; bottom: 20px; right: 20px; }
.sticky { position: sticky; top: 0; }

Flexbox

Flexbox is a layout model that allows elements to align and distribute space within a container.

Basic Flexbox Container
.flex-container {
  display: flex;
  justify-content: center;
  align-items: center;
}

CSS Grid

CSS Grid is a two-dimensional layout system for creating complex web layouts.

Basic Grid Container
.grid-container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 20px;
}

Pseudo-classes & Pseudo-elements

Pseudo-classes and pseudo-elements allow you to style elements in specific states or add content without modifying HTML.

Pseudo-classes
a:hover { color: red; }
input:focus { border-color: blue; }
li:nth-child(odd) { background-color: #f0f0f0; }
Pseudo-elements
p::before { content: "Note: "; }
p::after { content: " - End"; }
.quote::first-line { font-weight: bold; }

Advanced CSS Concepts

CSS Variables (Custom Properties)

CSS variables allow you to store and reuse values throughout your stylesheet.

Defining and Using CSS Variables
:root {
  --main-color: #3498db;
  --border-radius: 5px;
}

.button {
  background-color: var(--main-color);
  border-radius: var(--border-radius);
}

Transforms

Transforms allow you to rotate, scale, skew, or translate elements.

Transform Examples
.rotate { transform: rotate(45deg); }
.scale { transform: scale(1.2); }
.translate { transform: translate(10px, 20px); }
.skew { transform: skew(10deg, 5deg); }

Transitions

Transitions allow you to change property values smoothly over a specified duration.

Transition Example
.button {
  background-color: #3498db;
  transition: background-color 0.3s ease;
}

.button:hover {
  background-color: #2980b9;
}

Animations

Animations allow you to create complex animations using keyframes.

Animation Example
@keyframes slideIn {
  from { transform: translateX(-100%); }
  to { transform: translateX(0); }
}

.animated-element {
  animation: slideIn 0.5s ease;
}

Media Queries

Media queries allow you to apply different styles based on device characteristics.

Media Query Example
/* Desktop styles */
.container { width: 1200px; }

/* Tablet styles */
@media (max-width: 768px) {
  .container { width: 100%; padding: 0 20px; }
}

/* Mobile styles */
@media (max-width: 480px) {
  .container { padding: 0 10px; }
}

CSS Preprocessors

CSS preprocessors like Sass and Less add features like variables, nesting, and functions to CSS.

Sass Example
// Variables
$primary-color: #3498db;

// Nesting
.navbar {
  background: $primary-color;

  ul {
    margin: 0;
    padding: 0;

    li { list-style: none; }
  }
}
