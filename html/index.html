What is HTML?

HTML (HyperText Markup Language) is the standard markup language for creating web pages and web applications. It forms the backbone of the World Wide Web and is essential for anyone interested in web development, digital design, or creating online content.

HTML Document Structure

Learn the essential structure of HTML documents that all web pages use.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Web Page</title>
</head>
<body>
    <!-- Content goes here -->
</body>
</html>

Essential Elements

Master the core HTML elements used in all websites.

  • Headers (<h1>-<h6>) for structuring content
  • Paragraphs (<p>) for text content
  • Divisions (<div>) for layout containers
  • Spans (<span>) for inline styling

Forms and User Input

Creating interactive web experiences through forms is a crucial skill for web developers.

Best Practices for Forms

  • Always use appropriate input types for better UX and validation
  • Provide clear labels and instructions for form fields
  • Implement proper validation both client-side and server-side
  • Ensure forms are accessible to all users
  • Group related form elements with fieldsets

Accessibility Tip

Always associate form labels with their inputs using the "for" attribute to improve accessibility for screen readers.

Contact Form Example

A practical example of a well-structured contact form.

<form action="/submit" method="POST">
    <fieldset>
        <legend>Contact Information</legend>
        <div class="form-group">
            <label for="name">Full Name:</label>
            <input type="text" id="name" name="name" required>
        </div>
        
        <div class="form-group">
            <label for="email">Email Address:</label>
            <input type="email" id="email" name="email" required>
        </div>
        
        <div class="form-group">
            <label for="message">Message:</label>
            <textarea id="message" name="message" rows="5"></textarea>
        </div>
        
        <button type="submit" class="btn">Send Message</button>
    </fieldset>
</form>

Tables for Data Presentation

Organize tabular data effectively with semantic HTML.

<table>
    <caption>Student Grades</caption>
    <thead>
        <tr>
            <th scope="col">Student</th>
            <th scope="col">Subject</th>
            <th scope="col">Grade</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>John Doe</td>
            <td>Mathematics</td>
            <td>A</td>
        </tr>
        <tr>
            <td>Jane Smith</td>
            <td>Science</td>
            <td>B+</td>
        </tr>
    </tbody>
</table>

Semantic HTML and Accessibility

Creating inclusive web experiences that work for everyone, regardless of ability or device.

SEO Benefit

Semantic HTML improves search engine optimization by helping search engines understand your content structure.

ARIA Landmarks

Enhance navigation for assistive technologies with ARIA landmark roles.

<header role="banner">
    <!-- Site header content -->
</header>

<nav role="navigation" aria-label="Main Navigation">
    <!-- Navigation content -->
</nav>

<main role="main">
    <!-- Main content -->
</main>

<aside role="complementary">
    <!-- Supplementary content -->
</aside>

<footer role="contentinfo">
    <!-- Footer content -->
</footer>

Microdata for SEO

Structure data for better search engine visibility.

<article itemscope itemtype="http://schema.org/BlogPosting">
    <h1 itemprop="headline">HTML Best Practices</h1>
    <p itemprop="author" itemscope itemtype="http://schema.org/Person">
        By <span itemprop="name">John Developer</span>
    </p>
    <time itemprop="datePublished" datetime="2023-01-01">
        January 1, 2023
    </time>
    <div itemprop="articleBody">
        <p>Content of the article...</p>
    </div>
</article>
