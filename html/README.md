## Deployment to GitHub Pages

### Method 1: Automatic Deployment with GitHub Actions (Recommended)

This repository includes a GitHub Actions workflow that automatically deploys your site whenever you push changes to the `main` branch.

1. Create a new repository on GitHub
2. Push these files to your repository
3. Go to the "Actions" tab and enable workflows if prompted
4. The site will automatically deploy to GitHub Pages

### Method 2: Manual Deployment

1. Create a new repository on GitHub (or use an existing one)
2. Push these files to your repository
3. Go to Repository Settings
4. Scroll down to "Pages" section
5. Under "Source", select "Deploy from a branch"
6. Select "main" branch and "/root" folder
7. Click "Save"
8. Your site will be available at `https://username.github.io/repository-name`
