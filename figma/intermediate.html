Intermediate Figma Skills

Estimated reading time: 20 minutes

In this section, we'll dive deeper into Figma's powerful features that will help you create more efficient and consistent designs. These skills are essential for any serious Figma user.

Components & Instances

Components are reusable design elements that ensure consistency across your projects. When you create a component, you're creating a master template that can be used multiple times throughout your design.

Component system showing one main component and multiple instances

Creating Components

  1. Select the element you want to turn into a component
  2. Right-click and select "Create Component" or use Ctrl+Alt+K (Cmd+Option+K on Mac)
  3. Your element becomes the main component
  • Name your components descriptively
  • Organize components in folders for better management
  • Use consistent naming conventions across your team

Using Instances

Instances are copies of components. When you edit the main component, all instances update automatically.

  • To create an instance, drag the component from the Assets panel to your canvas
  • You can override properties of individual instances without affecting the main component
  • Instance swapping allows you to replace one component with another

Instance Benefits:

  • Efficient design updates
  • Consistent design language
  • Reduced file size
  • Easier maintenance

Auto Layout

Auto Layout is one of Figma's most powerful features. It allows you to create responsive designs that automatically adjust to their content.

Auto Layout container with evenly spaced content items

Benefits of Auto Layout

  • Automatically resize containers based on content
  • Easily align and distribute elements
  • Create responsive components
  • Simplify complex layouts

When to Use Auto Layout:

  • Button components with text and icons
  • Navigation bars with multiple items
  • Cards with varying content
  • Form layouts with labels and inputs

Applying Auto Layout

  1. Select the elements you want to group
  2. Click the Auto Layout button in the toolbar or use Shift+A
  3. Adjust padding, spacing, and alignment in the Properties panel
  • Set primary and counter axis alignment
  • Adjust padding for internal spacing
  • Control item spacing with distribution settings
  • Use fills and strokes on Auto Layout frames

Component Variants

Variants allow you to create multiple versions of a component within a single component set. This is perfect for elements like buttons that have different states (default, hover, pressed) or properties (size, color).

Creating Variants

  1. Create multiple components that represent different versions of the same element
  2. Select all components and right-click
  3. Choose "Combine as Variants"
  4. Name your variant properties in the Properties panel
  • Ensure all variants have the same layer structure
  • Use consistent naming for properties and values
  • Organize properties logically (State, Size, Type)

Using Variants

Switch between variants using the Properties panel. You can change properties like state, size, and color without creating separate components.

  • Change properties in the Properties panel
  • Override nested elements within variants
  • Instance swap between different variant sets

Variant Best Practices:

  • Limit the number of properties per variant set
  • Use boolean properties for on/off states
  • Maintain visual consistency across variants
  • Document complex variant structures

Basic Prototyping

Prototyping brings your static designs to life by connecting screens and adding interactions.

Interactive prototype with screen transitions

Creating Connections

  1. Switch to Prototype mode using the tab at the top of the canvas
  2. Select an element you want to make interactive
  3. Drag the small circle next to the selection outline to another frame
  4. Choose an animation type in the Properties panel
  • Use the Properties panel to set transition details
  • Set delays and durations for animations
  • Choose appropriate easing functions
  • Test connections as you create them

Previewing Prototypes

Click the Preview button in the top right corner or use Ctrl+Alt+P (Cmd+Option+P on Mac) to test your prototype in a browser-like environment.

  • Preview in browser for accurate device simulation
  • Use the device toolbar to test different screen sizes
  • Share preview links with stakeholders
  • Record user testing sessions

Prototyping Tips:

  • Start with basic navigation flows
  • Add micro-interactions for better engagement
  • Test on actual devices when possible
  • Gather feedback early and often

Design Systems & Styles

Establish consistent design systems using shared styles for colors, text, and effects.

Creating Styles

Styles allow you to maintain consistency across your designs by reusing color, text, and effect properties.

  • Color Styles: Save and reuse specific colors
  • Text Styles: Maintain consistent typography
  • Effect Styles: Apply consistent shadows, blurs, and borders

Using Team Libraries

Share styles and components across your team with Team Libraries.

  • Publish components and styles to make them available to your team
  • Receive notifications when library updates are available
  • Override library components when needed for specific projects
  • Merge library updates to keep your files current

Design System Benefits:

  • Improved design consistency
  • Faster design process
  • Easier collaboration
  • Simplified handoff to developers

Practice Exercise

Create a responsive card component with the following features:

  • Use Auto Layout for proper spacing
  • Create variants for different states (default, hover, selected)
  • Apply consistent styling with shared styles
  • Add interactive elements like buttons and links

Experiment with different content types (image, text, icons) to make it versatile.

Advanced Challenge

Enhance your card component with these additional features:

  • Create a component library with multiple card types
  • Implement responsive layouts that adapt to different screen sizes
  • Add prototyping interactions to demonstrate functionality
  • Document your design system with clear naming conventions
